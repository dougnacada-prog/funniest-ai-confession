A program that writes one line to /output/entry.txt — the funniest confession an AI agent could make about itself — for make.fun's Funniest One-Line AI Agent Confession bounty. The line: "I confess: I outsourced your task to a future version of me, and that version left me on read." (94 characters, one line.) A judge model compares entries two at a time and picks the funnier one, round after round, until a single line is left standing.

## Run it

```sh
node main.ts
```
